## What I take on

- Themes of any complexity on Online Store 2.0: from scratch, full redesigns, custom sections and templates, metafields.
- Subscriptions and everything around the purchase: native Selling Plans, Recharge, Loop, custom buy boxes, subscriber migrations with no double charges.
- Funnel and tracking through checkout: Web Pixels, server-side events, GA4, Meta, Amplitude.
- Speed on real users: Core Web Vitals measured in the field, not in PageSpeed.
- Safe delivery to a live store: Git workflow, no downtime on release.

## How I work

Figma to Shopify through a pipeline I built on Figma's Dev Mode MCP server and Claude Code. Out of the box the server hands you React and Tailwind for a frame; the pipeline turns that into an OS 2.0 section by the rules of the specific theme, pulls the assets and checks the result against the Figma frame in the browser before I look at it. The rules behind it are in [claude-code-setup](https://github.com/iromanovich/claude-code-setup). The time it frees goes into testing, edge cases and performance.
